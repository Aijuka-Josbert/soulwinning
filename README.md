# Soul Winning Mission Church – Mbalwa

This is a complete static website for Soul Winning Mission Church, a real local church in Mbalwa, Wakiso District, Uganda.

**Live URL:** (to be deployed)

---

## Project Overview

The website is designed to feel warm, authentic, and human—communicating the church's story, faith, community, and mission. It avoids generic AI-generated design patterns and uses a restrained, editorial aesthetic.

### Key Features

- Responsive navigation with mobile hamburger menu.
- Editorial layout with varied section styles (timeline, journey steps, grids).
- Placeholder images with Font Awesome icons for all photography.
- Event listing with recurring events and placeholders.
- Gallery with category filtering.
- Visit page with address, phones, weekly program, and map placeholder.
- Social media placeholders (no fake links).
- SEO-ready with unique titles and meta descriptions per page.

---

## Technology Stack

- **HTML5**, **CSS3**, **JavaScript**
- **Font Awesome** for icons
- No framework (React, Vue, etc.) – clean static frontend
